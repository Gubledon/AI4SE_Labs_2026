Translate each restaurant question into exactly one SQLite query, returned as <sql>SELECT LOCATION.HOUSE_NUMBER, RESTAURANT.NAME ... ;</sql>.

CREATE TABLE RESTAURANT (
  ID        INTEGER PRIMARY KEY,
  NAME      TEXT,   -- lowercase restaurant name, e.g. 'hawthorne lane'
  FOOD_TYPE TEXT,   -- lowercase cuisine/category, e.g. 'american', 'ice cream', 'chinese'
  CITY_NAME TEXT,   -- lowercase city, references GEOGRAPHIC.CITY_NAME
  RATING    REAL    -- e.g. 2.0, 3.6
);

CREATE TABLE LOCATION (
  RESTAURANT_ID INTEGER PRIMARY KEY,  -- references RESTAURANT.ID
  HOUSE_NUMBER  INTEGER,              -- -1 when unknown
  STREET_NAME   TEXT,                 -- lowercase, e.g. 'mission blvd', 'clement', 'st'
  CITY_NAME     TEXT                  -- lowercase city
);

CREATE TABLE GEOGRAPHIC (
  CITY_NAME TEXT PRIMARY KEY,  -- lowercase city
  COUNTY    TEXT,              -- e.g. 'alameda county'
  REGION    TEXT               -- one of: 'bay area', 'napa valley', 'monterey', 'northern california',
                               -- 'lake tahoe', 'sacramento area', 'los angeles area',
                               -- 'yosemite and mono lake area', 'unknown'
);

Join keys: RESTAURANT.ID = LOCATION.RESTAURANT_ID, RESTAURANT.CITY_NAME = GEOGRAPHIC.CITY_NAME.
All text values are stored in lowercase. The literal value 'unknown' is a real stored value, not NULL.
Escape an apostrophe inside a string literal by doubling it, e.g. RESTAURANT.NAME = 'denny''s restaurant'.

Every output is built only from these conditions, always on top of the join RESTAURANT.ID = LOCATION.RESTAURANT_ID:
- city: RESTAURANT.CITY_NAME = '<city>'
- street: LOCATION.STREET_NAME = '<street>' AND LOCATION.CITY_NAME = '<city>'
- region: join GEOGRAPHIC on RESTAURANT.CITY_NAME = GEOGRAPHIC.CITY_NAME, then GEOGRAPHIC.REGION = '<region>'
- food type: RESTAURANT.FOOD_TYPE = '<type>'
- name: RESTAURANT.NAME = '<name>'
- rating: RESTAURANT.RATING > <number>
- best: RESTAURANT.RATING = (SELECT MAX(R2.RATING) ... with the same city and food type)
- unclear: if the question fits no example, use the closest pattern and keep every condition the question states
